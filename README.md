# AI 職場全效生產力應用班｜招生網頁

單頁式招生 Landing Page，可直接部署至 GitHub Pages。

## 檔案
- `index.html`：完整招生頁面

## GitHub Pages 上線方式
1. 建立新的 GitHub Repository。
2. 將本資料夾內的 `index.html`、`README.md` 上傳到 Repository 根目錄。
3. 到 Repository → **Settings** → **Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**。
6. 等待 GitHub 產生公開網址即可。
